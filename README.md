# Valoración de potros · CENRE – Yeguada Cartuja · EUnetHorse

App web para valorar ejemplares (destete, 18 meses y 42 meses) en el 5º Training and Demo Day de EUnetHorse España.

Ábrela en el navegador del móvil (en iPhone, con Safari) y añádela a la pantalla de inicio para usarla sin conexión.

Financiado por la Unión Europea · Horizon Europe #101086551

Incluye [html5-qrcode](https://github.com/mebjas/html5-qrcode) (licencia Apache 2.0) para leer códigos de barras del microchip y el UELN.
